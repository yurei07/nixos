Only your computer

NIHIL talks to nothing but your own computer, and only once you pair it as a deck. No ads, no analytics, no account.

SET_WALLPAPER
The wallpaper studio, and NIHIL's wallpaper the first time it is home
EXPAND_STATUS_BAR
Swipe down for the notifications
REQUEST_DELETE_PACKAGES
Uninstall, in an app's menu
INTERNET
The deck, only ever to the computer it was paired with
CAMERA
Reading the computer's pairing QR; the frames never leave the phone
POST_NOTIFICATIONS
Telling you when the computer sends something
Notification access optional
The light on the frame and the unread icons: which app posted, never the text
Accessibility optional
The double tap to lock, and the light over other apps; it reads nothing on the screen

Install

Android 12 or newer.

  1. Download the APK

    From the latest release, with a .sha256 beside it to check it.

  2. Install it

    Open it on the phone, and let your browser or file manager install apps when Android asks.

  3. Make it your home screen

    Open NIHIL and tap Home app. The light on the frame and the double tap are off until you turn them on there.

From source

JDK 17 and the Android SDK, or the Nix shell in the repository, with the phone on USB or wireless debugging.

git clone https://github.com/poligle/Nihil-Launcher nihil-launcher
cd nihil-launcher
nix develop
./gradlew installDebug
